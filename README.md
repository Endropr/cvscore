# CVScore — AI Resume Analyzer

SaaS для проверки резюме на прохождение ИИ-скрининга: индекс доверия, оценки по 6 критериям, подходящие роли, красные флаги и конкретные правки формулировок.

**Демо:** https://cvscore-ten.vercel.app

## Стек
Vite · React 18 · TypeScript · Tailwind CSS · Framer Motion · pdf.js · OpenRouter (LLM) · Vercel Functions

## Возможности
- Загрузка PDF, DOCX, TXT (текст извлекается прямо в браузере) или вставка текста
- Анализ через LLM: индекс доверия, 6 критериев, роли с требованиями вакансий, красные флаги, таблица правок
- Тарифы 299 ₽ / 399 ₽ (в демо разблокировка без оплаты, платёжный шлюз ещё не подключён)

## Архитектура
Браузер → `POST /api/analyze` (серверная функция Vercel) → OpenRouter.
Ключ API хранится только на сервере и в браузер не попадает. Промпт, модель и лимиты тоже на сервере (`api/analyze.js`).

## Экономия токенов
- Резюме обрезается до 12 000 символов
- Строгий формат ответа (только JSON), без лишнего текста
- Для «думающих» моделей `reasoning.effort = low`
- По умолчанию используются бесплатные модели OpenRouter; цепочка с автоматическим переключением при ошибках (`api/analyze.js`)
- Лимит 15 анализов в час с одного IP
- Расход токенов каждого запроса пишется в логи функции (Vercel → Logs) и показывается в консоли браузера; сводка — в OpenRouter → Activity

## Запуск локально
```
npm install
cp .env.example .env   # вставьте OPENROUTER_API_KEY
npm run dev
```
Переменные: `OPENROUTER_API_KEY` (обязательно), `OPENROUTER_MODEL` (необязательно, например `nvidia/nemotron-3-ultra-550b-a55b:free`).

## Разработка с ИИ
Проект разработан с помощью ИИ-инструментов (LLM для генерации кода и дизайна). Первоначальный промпт — в [PROMPT.md](PROMPT.md).

## Известные ограничения
Бесплатные модели имеют лимиты и иногда отвечают нестабильно; платёжная система не подключена; сканированные PDF (картинки) не распознаются.
